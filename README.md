# Multiplayer Survival Game

The Floor is Evolving is a multiplayer survival game where players enter an arena made from a grid of floor tiles. Every round, the floor begins changing into increasingly dangerous forms, such as lava, ice, disappearing tiles, bounce tiles, collapse tiles, and electrical tiles. Players must pay attention to warnings, react quickly, move to safe areas, and survive until the round ends. Each round should feel different because the hazard sequence, affected tiles, and combinations change. The game is designed to be easy to understand in the first 10 seconds but interesting enough that players want to improve, unlock cosmetics, and return for another round.

## Install

1. Open Roblox Studio.
2. Create a new place or open an existing one.
3. Navigate to the ServerScriptService in the Explorer.
4. Insert the scripts into the ServerScriptService.

## Use

1. Run the game to start playing.
2. Use WASD or arrow keys to move.
3. Use the spacebar to jump.
4. Hold the left shift key to sprint.
5. Hold the left control key to crouch.
